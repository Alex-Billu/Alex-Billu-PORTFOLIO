# Alex-Billu-PORTFOLIO

Personal portfolio website showcasing my skills, projects, achievements, certifications, and experience as an AI Developer and Full Stack Developer.

## Features

- Responsive portfolio with light and dark themes
- Interactive project gallery and visual effects
- Downloadable AI/ML and full-stack resumes

## Run locally

Serve the project directory with any static HTTP server, then open the local address in your browser. For example, with Python installed:

```bash
python -m http.server 8000
```

Visit [http://localhost:8000](http://localhost:8000). The site loads its main page from `index.html`; no package installation or build step is required.

## Project files

- `index.html` — portfolio page and main layout
- `public/projects-data.js` — project gallery content
- `public/projects-gallery.js` and `public/projects-gallery.css` — gallery behavior and styles
- `public/projects-visuals.js` — interactive visual effects
- `public/resume-ai-ml.pdf` and `public/resume-fullstack.pdf` — downloadable resumes
